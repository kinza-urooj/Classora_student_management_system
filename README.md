#Classora — Student Management Dashboard

A beginner-friendly Python + Flask mini project with a dark dashboard design.

## Python topics included
- Variables and data types
- Input and type conversion
- If / elif / else
- Loops
- Lists
- Functions and methods
- OOP: class, objects, constructor, attributes
- JSON file handling (save and load records)
- CSV export
- Flask routes and HTML templates

## Features
- Dashboard stats: total, passed, failed, average and attendance
- Add students with marks and attendance
- Automatic average, grade and pass/fail calculation
- Search students by name or roll number
- Delete student records
- Export student report as CSV
- Save student records in JSON so data stays after restart

## Run on Windows (VS Code)
1. Extract this folder.
2. Open the folder in VS Code.
3. Open Terminal: **Terminal → New Terminal**.
4. Install Flask:
   `python -m pip install -r requirements.txt`
5. Start:
   `python app.py`
6. Open this address in your browser:
   `http://127.0.0.1:5000`

This is a learning/demo project. The Flask development server is not intended for public production deployment.
